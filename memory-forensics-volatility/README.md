# Memory Forensics (Volatility)

Analyzed a Windows memory image using Volatility 3 to extract forensic artifacts and investigate system activity.

## Tools Used
- Volatility 3

## Skills Demonstrated
- Process analysis
- User session identification
- Memory artifact investigation
- Timeline reconstruction

## Key Findings
- Identified system boot time
- Enumerated user accounts and login sessions
- Analyzed running processes
- Investigated environment variables and system activity
