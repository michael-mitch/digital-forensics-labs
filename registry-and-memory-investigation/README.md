# Registry and Memory Investigation

Performed forensic analysis using Registry Ripper, Volatility, and WinPrefetchView to identify suspicious activity, malware behavior, and evidence of compromise.

## Tools Used
- Registry Ripper
- Volatility
- WinPrefetchView

## Skills Demonstrated
- Registry hive analysis
- Prefetch analysis
- Process correlation
- Malware identification
- Network artifact investigation
- Timeline reconstruction

## Key Findings
- Identified fake system processes attempting impersonation
- Correlated suspicious network activity with rogue processes
- Detected RAT-like behavior and persistence indicators
- Investigated executed programs and user activity artifacts
