# Digital Forensics Labs

This repository contains hands-on digital forensics labs and analysis projects focused on memory forensics, malware investigation, artifact analysis, steganography, and forensic methodology.

## Skills Demonstrated
- Memory forensics
- Malware analysis
- Artifact and metadata analysis
- Process and network correlation
- Timeline reconstruction
- Steganography analysis
- Digital evidence handling

## Tools Used
- Volatility 3
- RegRipper
- ExifTool
- WinPrefetchView
- SNOW
- S-Tools
- StegoMagic

## Lab Categories

### Malware Analysis
Investigated suspicious processes, credential theft, RAT behavior, and malicious network activity using forensic artifacts.

### Memory Forensics
Analyzed Windows memory images to identify users, processes, sessions, and system artifacts.

### Steganography Analysis
Performed hidden data embedding and extraction using multiple steganography tools.

### Forensic Investigation Process
Explored evidence handling, preservation, and digital forensic procedures.

### NTFS Artifact Correlation
Analyzed NTFS artifacts including the MFT, $LogFile, and $UsnJrnl to reconstruct system activity and identify tampering.

## Notes
These labs were completed as part of hands-on digital forensics and cybersecurity training to develop practical investigation and analysis skills.
