# NTFS Artifact Correlation Analysis

Analyzed NTFS file system artifacts to reconstruct system activity and identify potential tampering or anti-forensic behavior.

## Key Concepts
- Master File Table (MFT) analysis
- $LogFile transaction analysis
- $UsnJrnl change tracking
- MAC timestamp analysis
- Artifact correlation

## Skills Demonstrated
- Timeline reconstruction
- File system forensic analysis
- Detection of anti-forensic techniques
- Artifact correlation and interpretation

## Overview
This project demonstrates how multiple NTFS artifacts can be correlated to reconstruct user and system activity while identifying inconsistencies and evidence of tampering.
